# AI assistance and third-party components

## How AI was used to build this

Stated plainly, because a vague answer here reads worse than an honest one.

**Claude Code (Anthropic) wrote the great majority of this repository**, working from a
specification the team prepared in advance (`docs/MASTER_PLAYBOOK.md`) and a set of frozen
decisions (`docs/COMMAND_BRAIN.md`). That includes the domain logic, the schema and migrations,
the API, the agent layer, the interface, the tests, and these documents.

What the team supplied and remains accountable for: the problem choice and scope, the competition
requirements, the decision to freeze a single corridor and fixture, the environment and database,
and the final judgement about which claims are true.

### What that does and does not mean

- Every number in the golden fixture was **verified by hand** against the specification before the
  implementation existed, and the tests assert those figures independently of the code.
- Two high-severity defects (an obligation could be overpaid; the payee could be redirected after
  approval) were found by the same assistant reviewing its own work adversarially, and both are
  written up in `docs/REVIEW_FINDINGS.md` rather than quietly fixed.
- **No independent human or second-tool review has been performed.** A reviewer that shares the
  author's blind spots shares its mistakes, and that limitation is recorded everywhere it matters.
- No test result, measurement or citation in this repository was generated by asking a model what
  the answer probably is. Every figure quoted in the reports came from a command that was run.

### AI inside the product

The shipped application calls a model API through its own backend adapter
(`src/lib/agent/adapter.ts`). That is a separate thing from the coding assistant, and a coding
subscription is not an application credential.

**In this build there is no configured model credential, so no live model run exists and none is
claimed.** The agent's tool boundary is fully tested with a scripted stub, and stub results are
never merged with live results.

### Competition disclosure

If the organizers require a specific AI-assistance declaration format, this file is the source of
truth for the facts; the team will restate them in whatever form is asked for. Nothing here is
intended to minimise the extent of AI involvement.

Licence identifiers are taken from each package's published metadata. The team should confirm them
against the installed packages before submission if the organizers require a formal notices file;
`npm ls --all` and the packages' own LICENSE files are authoritative over this table.

**No datasets, icon sets, fonts or images from third parties are bundled.** The interface uses
system fonts and no icon library. All content, names, providers and figures are invented for this
project.

**No real provider SDK is integrated.** The payment simulator is our own code
(`src/lib/simulation/simulator.ts`) and is labelled simulated in every record it produces.
